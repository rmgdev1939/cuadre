# Cuadre

Control de caja multimoneda (USD / Bs con tasa BCV) para comercios. App web instalable que funciona sin conexión; los datos de cada comercio se guardan solo en su teléfono.

**Abrir e instalar:** https://rmgdev1939.github.io/cuadre/

- Android: abrir en Chrome → menú ⋮ → Instalar app.
- iPhone: abrir en Safari → Compartir → Agregar a inicio.

Hecha con HTML, CSS y JavaScript sin frameworks. Publicada con GitHub Pages desde la rama `main`, carpeta raíz.
